# 部署

交付：`TouchLock-1.0.0-Setup-x64.exe`、源码 ZIP、SHA256SUMS。安装程序嵌入 App/Service/Recovery 与完整 .NET x64 运行时，安装不联网。

支持目标 Windows 10/11 x64 的普通桌面环境。有标准触摸屏时先核对锁定/恢复和键鼠不受影响。无触摸屏时托盘会显示不可用，仍可设置/修改口令与执行口令退出。

1. 如安装过旧驱动版，先卸载旧服务和 TouchLockFilter；当前版本不卸载或替换原厂驱动。
2. 双击安装包并接受 UAC，按需修改安装位置，再设置独立口令。默认 `%ProgramFiles%\TouchLock`，也可使用本地 NTFS 磁盘的新文件夹，例如 `D:\TouchLock`。
3. 确认托盘存在，在 About 查看设备/快捷键状态。
4. 通过开始菜单启动；默认关闭自启动。托盘“开机自启动”验证管理口令后切换服务为自动/按需启动，UI 查询真实 SCM 配置。没有自动更新。
5. 需要维护时运行安装包，或使用 Windows 应用卸载入口。卸载须先验证当前管理口令，再恢复全部已记录设备；错误或取消保持原安装和服务状态。忘记口令可由 Windows 管理员先重置。

冰点环境需临时解冻系统盘，将应用安装到非冻结 NTFS 盘，配置自启动并完成重启检查后再冻结。服务注册、安装位置及自启动设置属于 Windows 系统配置，必须纳入保存；应用数据跟随安装盘，不依赖冻结的用户目录。驱动证书、测试签名模式、Secure Boot 和 HVCI 设置无需修改。

安装目录及新建上级目录由 Administrators 拥有，SYSTEM/Admin 可写，Users 只读/执行；不修改已有父目录权限。实际安装和数据位置记录在 HKLM 卸载项的 InstallLocation/DataLocation。数据优先使用安装盘 ProgramData/TouchLock，父目录不安全时使用同盘 TouchLockData；两处均不安全则拒绝，不回退系统盘。口令、恢复记录及 Logs 仅 SYSTEM/Admin 可访问。

默认卸载保留当前数据目录；显式删除配置只删除本程序管理的文件和日志，保留未知文件。旧版迁移源保留为备份，不在新位置卸载时擅自删除。安装程序的临时维护副本保持 Admin/SYSTEM ACL，使用后安排重启清理。
