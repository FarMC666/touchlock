# 恢复与口令维护

锁定时保留鼠标或物理键盘。解锁和退出必须输入管理口令；六指和触摸认证已经移除。

| 情况 | 行为 |
| --- | --- |
| 托盘被结束 | 不解锁，服务约十秒内尝试恢复托盘 |
| 托盘口令窗口被结束 | 返回认证前状态 |
| 服务退出 | SYSTEM 恢复进程立即开始恢复 |
| 服务心跳失联 | 约30秒后先结束原服务，再恢复；SCM 尝试重启 |
| 恢复进程退出 | 服务恢复触摸并拒绝继续锁定 |
| 设备热插拔/异常 | 撤销本次锁定；移除节点保留恢复记录并重试 |
| 锁屏/注销/切换用户/睡眠 | 恢复本次禁用的设备，取消认证 |
| 重启 | 不恢复旧锁定；禁用未设持久化标志 |

忘记口令：以 Windows 管理员身份运行安装程序维护，点击“重置忘记的管理口令”。先恢复触摸，再设置新口令。知道软件口令与拥有 Windows 管理员权限是两个不同权限。

卸载：点击安装程序中的“卸载 TouchLock”，输入当前管理口令，验证成功后才恢复设备并卸载。错误或取消不会停止服务或移除安装；口令配置缺失或损坏时拒绝卸载，需要管理员先重置口令。

恢复失败时不要删 `recovery.json`；重连相关触摸设备再维护。若键鼠均不可用，通过电脑物理电源/系统重启应急恢复。正常锁定没有自动解除倒计时。

本机管理员可以停止服务、改配置或卸载。本软件不防御管理员、SYSTEM、内核故障或硬件故障。恢复机制保留错误记录，并以可恢复操作优先。
