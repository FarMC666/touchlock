# TouchLock 1.0.0

临时锁定 Windows 标准 HID 触摸屏输入，保留鼠标与物理键盘操作。适用于 Windows 10/11 x64。

## 安装

双击 `TouchLock-1.0.0-Setup-x64.exe`，接受管理员 UAC 提示，点击“安装并设置管理口令”。设置并确认 8～128 字符的独立口令后，程序进入系统托盘。安装包包含 .NET 运行时；不需要另装 .NET、驱动证书、WDK 或测试模式。

安装目录默认为 `%ProgramFiles%\TouchLock`，可在安装窗口输入自定义路径，或点击“浏览...”选择上级文件夹。支持本地 NTFS 固定磁盘中的新文件夹，例如 `D:\TouchLock`；不覆盖已有文件夹，不安装到普通用户可替换的上级目录。安装后维护与卸载会自动读取实际位置。开始菜单中可再次启动 TouchLock。默认不设置开机自启。

## 使用

- `Ctrl + Win + Alt + Enter` 或托盘“锁定触摸”：静默锁定。重复快捷键不会解锁。
- “解除触摸锁定...”：输入管理口令，恢复触摸。恢复前移开屏幕上的手指。
- “禁止进入 Windows 蓝牙设置”：勾选无需口令；进入系统“设置”的蓝牙页面时自动关闭设置窗口。取消勾选须验证管理口令，错误或取消保持勾选；不改变触摸锁定状态。
- “修改管理口令...”：输入当前口令与新口令。
- “退出...”：无论是否锁定均需口令；恢复设备后退出服务与托盘。
- “关于 TouchLock”：查看版本、设备不可用原因或快捷键冲突。

锁定期间触摸屏设备被临时禁用。认证必须使用鼠标或物理键盘；屏幕键盘可以由鼠标操作。**本版没有六指解锁，也没有触摸认证。** 请保留可用的鼠标或物理键盘。

蓝牙设置限制支持 Windows 10/11，默认未勾选。勾选状态会保存，重新打开 TouchLock 后继续生效；没有触摸屏时也可使用。监控仅在托盘运行期间生效，不关闭蓝牙、不改变设备配对，其他设置页面仍可使用。此选项限制系统“设置”中的蓝牙页面，不限制任务栏快速设置、传统控制面板或第三方蓝牙工具。

## 忘记口令与卸载

重新打开安装包，或在 Windows“已安装的应用”中选择 TouchLock 卸载，进入管理员维护界面。点击“卸载 TouchLock”后须输入当前管理口令；验证成功才恢复设备并卸载，错误口令或取消不会停止服务、恢复触摸或删除文件。默认保留口令与蓝牙限制配置，勾选“卸载时同时删除口令和蓝牙限制配置”会一并删除。

忘记口令时，Windows 管理员仍可使用“重置忘记的管理口令”；此恢复入口先恢复设备，再设置新口令，然后使用新口令卸载。

恢复失败时会保留恢复记录，拒绝伪报成功或继续卸载。重新连接移除的触摸设备后重试；需要应急恢复时重启 Windows。

## 边界

- 只支持独立的标准 HID Touchscreen 集合；不操作键盘、鼠标、笔、触控板或父设备。检测到混合输入或同设备的鼠标通道时拒绝锁定。厂商私有输入通道仍需在目标电脑验收。
- 手机远程软件注入的触摸消息不一定对应 HID 触摸屏。UU 平板触控模式可用于检查界面触摸响应；本机已观察到注入的触摸事件，但未枚举到标准触摸屏，不能用它验收设备锁定与恢复。
- 不设置跨重启禁用标志。重启、锁屏、注销、切换用户、睡眠及设备变化会恢复触摸；锁定状态不持久化。
- 结束托盘不会解锁。服务监督托盘并尝试重启；服务退出或心跳中断约 30 秒后由独立 SYSTEM 恢复进程恢复设备。恢复进程异常时服务恢复触摸并停止锁定功能。
- 本机管理员可以通过维护界面恢复与重置口令；本工具不抵抗管理员或 SYSTEM，也不代替 Windows 访问控制。
- 无微软发布者签名的普通安装程序可能显示“未知发布者”或来源提示。无需购买证书或关闭系统签名检查。S 模式及企业应用白名单环境不承诺支持。
- 检测到旧版 TouchLock 服务或 TouchLockFilter 时不覆盖，必须先卸载旧版。

## 从源码构建

安装 .NET 10 SDK（`global.json` 规定版本）与 PowerShell 7。无需 Visual Studio 或 WDK：

```powershell
pwsh -File scripts/build.ps1 -Configuration Debug
pwsh -File scripts/build.ps1 -Configuration Release
```

构建会运行核心测试并发布自包含安装包。产物位于 `artifacts/`：安装程序、完整源码 ZIP 与 SHA256 校验和。

详细设计见 [架构](docs/architecture.md)，恢复操作见 [恢复说明](docs/recovery.md)，验证范围见 [验证说明](docs/validation.md)。
